# Grupo Ciatto

**Tecnologia, produtos digitais e soluções para negócios.**

O ecossistema Ciatto reúne iniciativas de desenvolvimento de software, automação e comunicação digital. Aqui documentamos projetos, compartilhamos informações institucionais e conectamos os canais oficiais de cada solução.

## Produtos e projetos

### Gestly — gestão de agendamentos
Plataforma de organização de horários, serviços, profissionais e reservas online para negócios que atendem com hora marcada.

- [Conhecer a Gestly](https://gestly.co/)
- [Apresentação no GitHub](https://github.com/ciatto/gestly)

### Sendbot — chatbots e automação de conversas
Plataforma para criar experiências de atendimento digital e automatizar jornadas de conversa.

- [Conhecer o Sendbot](https://sendbot.co/)
